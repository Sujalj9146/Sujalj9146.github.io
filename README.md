# Sujal Jadhavar · Portfolio

My personal portfolio website: projects, experience, skills and contact.

**Live:** https://sujalj9146.github.io

Built from scratch with plain HTML, CSS and JavaScript. No frameworks or build step.

```
index.html      page structure
css/style.css   design system, layout, light and dark themes
js/main.js      project data, project details dialog, theme toggle, scroll effects
images/         profile photo
```

To run locally, serve the folder (for example `python -m http.server`) and open http://localhost:8000.
